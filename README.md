# Zapret для WARDOGS

Windows-профиль сетевого инструмента Zapret, подготовленный 28.09.2026 на основе комплекта 1.10.3. `general (ALT11).bat` задаёт отдельные параметры TCP и UDP для игровых адресов. Это конфигурация, а не самостоятельное приложение.

## Состав этой копии

Здесь оставлены профиль и [исходная инструкция](README-WARDOGS.txt). Для запуска ему нужны файлы исходного комплекта Zapret: `service.bat`, `bin/winws.exe`, WinDivert, файлы шаблонов `bin/*.bin` и списки `lists/*`. Их происхождение и условия распространения нужно сверить до включения в публичную сборку. В текущем виде папка предназначена для просмотра, а не запуска.

README исходного профиля прямо говорит, что подключение к игре без VPN не подтверждено. Результат зависит от сети; общие облачные IP не изолируют трафик только одной игры.
